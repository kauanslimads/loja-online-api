# Especificacao dos requisitos

- RF01 (Páginas de categorias) - deve possuir páginas específicas para cada categoria registrada no sistema
- RF02 (Pesquisa de produtos na loja) - deve permitir que usuários busquem produtos através de uma barra de pesquisa
- RF03 (Página individual de produtos) - deve permitir que usuários naveguem para a página individual dos produtos
- RF04 (Filtragem dos produtos)- deve permitir que usuários filtrem produtos com base nas características básicas, como preço, categoria, marca e etc
